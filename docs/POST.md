# iQOO Neo9S Pro 全屏熄屏（全天候 AOD）开了！KSU + LSPosed 双模块

> 酷安 @小雨爱分享
> #iQOONeo9SPro# #OriginOS6# #全屏熄屏# #AOD# #KernelSU# #LSPosed#

---

先说结论：**Neo9S Pro 的全屏熄屏（官方叫"全天候熄屏显示"）能开了**，锁屏后整块屏压暗当 AOD 用，时间、通知实时刷新，效果接近原厂。

## 为什么会没有

Neo9S Pro 和 iQOO 12 / Neo9 是同一块 8T LTPO 屏，硬件完全支持，但 vivo 在固件里用**机型白名单**把它藏了：

- 「熄屏显示」这个 App 里判断条件是 `机型数字 >= 2436`，而 PD2339 抠出来是 2339，硬性不达标；
- 面板能力文件 `/sys/lcm/aod_disp_info` 里也写着 `support_full_screen=0`。

所以官方"硬件不支持"只是说辞，改判断就能放出来。

## 怎么实现的

两个模块分工：

- **KSU 模块**：开机写属性 `ro.vivo.keyguard_full_aod.enable=1`、修正面板能力串、写好 AOD 类型；
- **LSPosed 模块**：只钩「熄屏显示」App 里的 4 个判断（机型白名单那几个布尔），别的什么都不动。

只装 LSPosed 也能出效果；两个一起最完整。

## 效果

- 锁屏后整屏压暗，壁纸 + 大时钟 + 通知；
- 时间、消息通知**实时刷新**；
- 有 AOD 该有的呼吸感，不再是"只有指纹图标"。

## 安装

1. KSU 管理器刷 `Neo9SP_aod_ksu_v3.0.zip`（12KB）；
2. 安装 `Neo9SP_aod_lsp_v2.4.apk`，LSPosed 里启用，作用域点「**推荐**」（已内置 `com.vivo.nightpearl` + `com.android.systemui`）；
3. 重启。

## 用之前必须做的两件事

1. **设置 → 桌面、锁屏与壁纸 → 熄屏显示 → 熄屏类型 → 选「全屏熄屏」**；
2. **熄屏显示 → 更多熄屏设置 → 显示方式 → 选「全天显示」**
   （选"轻移手机显示 / 定时显示"时，静止一会儿 AOD 会整块熄灭，别以为是坏了）。

## 配置文件

`/data/adb/iqoo_pd2339_fullaod/config.ini`，改完点模块「执行 / Action」立即生效：

```
AOD_TYPE=2        # 1 局部 / 2 融合（唯一能实时刷新的）/ 3 全屏（静态）
MOUNT_SYSFS=1     # 是否修正面板能力串
SMART_AOD=        # 填 0 可尝试关闭"智能熄屏"（静止也刷新）
DISABLE=0         # 填 1 一键退回原厂
```

## 已知 Bug（欢迎大牛来修）

| # | 现象 | 临时解决 |
|---|---|---|
| 1 | 切回局部熄屏再切回全屏后，实时刷新失效 | 在 KSU 管理器点一下模块「执行 / Action」 |
| 2 | 进 AOD 会先黑一下（实测约 0.8~1 秒），亮屏也会闪一下 | 暂无 |
| 3 | 目前只有时间和消息通知实时刷新 | 暂无 |

已经排除的方向（省得再踩）：不是 CPU 挂起（wakelock 无效）、不是 SystemUI 判断、不是伪造面板串、也不是 App 动画——黑屏是显示栈从亮屏切 AOD 的时序，应用层够不着。

## 注意

- 改系统行为有风险，出问题：删 KSU 模块 + 停用 LSPosed → 重启即可完全恢复；
- 只对本机型（PD2339 / V2338A）和 `熄屏显示 8.0.4.2` 验证过，其他机型自行测试；
- 代码和说明都开源了，BUG 里那三条欢迎 PR 👉（GitHub 链接待补）
